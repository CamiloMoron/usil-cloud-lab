Laboratorio: Despliegue de una aplicación web mediante contenedores Docker

Objetivo del Laboratorio

Construir, empaquetar y publicar una aplicación web estática dentro de un contenedor Docker ligero optimizado con Nginx Alpine, alojando la imagen en Docker Hub y desplegándola en una infraestructura cloud accesible públicamente mediante HTTPS.

Arquitectura del Proyecto

1
Código Web
2
Dockerfile
3
Docker Build
4
Docker Hub
5
Blitz Cloud

Proceso de Despliegue

  1. Estructuración del frontend: Creación del archivo index.html con diseño semántico y responsive.
  2. Definición del contenedor: Configuración del Dockerfile basado en nginx:alpine.
  3. Compilación multiplataforma: Construcción de la imagen local con docker build --platform linux/amd64.
  4. Distribución en registro: Publicación de la imagen en Docker Hub mediante docker push.
  5. Aprovisionamiento en la nube: Despliegue en Blitz Cloud y validación de conectividad HTTPS.
